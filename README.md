# tablet-submonitor

갤럭시탭 S8 Ultra를 USB로 연결해 이 맥북의 확장 모니터로 쓰는 개인용 도구 (1차: macOS 전용).

- 맥: 가상 디스플레이(2960×1848, HiDPI 1480×924, 120Hz)를 만들고 FFmpeg로 HEVC 압축해 보낸다.
- 커서는 영상에서 빼고 좌표·모양만 따로 보내 탭이 직접 그린다(커서 지연 최소화).
- 탭: MediaCodec 하드웨어 디코딩, 받은 프레임을 쌓지 않고 바로 표시한다.

설계: `docs/superpowers/specs/2026-11-25-tablet-submonitor-design.md`

## 준비

- 탭: 설정 → 휴대전화(태블릿) 정보 → 소프트웨어 정보 → 빌드번호 7번 → 개발자 옵션 → USB 디버깅 켜기 → 맥에 연결 후 "항상 허용"
- 맥: `ffmpeg`, `adb`가 PATH에 있어야 한다. Android SDK(`android/local.properties`의 `sdk.dir`), JDK 21, Xcode
- 맥: 처음 실행할 때 터미널 앱에 화면 기록 권한을 준다
  (시스템 설정 > 개인정보 보호 및 보안 > 화면 및 시스템 오디오 녹음)

## 실행

```sh
./run.sh               # 탭 앱 빌드·설치, 호스트 실행. Ctrl-C로 종료
./run.sh --fps 60      # 프레임 간격을 고르게(기본은 120 요청, 실제 약 80fps)
./run.sh --bitrate 60M # 글자가 뭉개지면 올린다(기본 40M)
```

USB를 뺐다 다시 꽂으면 자동으로 다시 연결된다. 종료하면 가상 디스플레이와 탭 앱이 정리된다.

## 지연 측정

1. `tools/latency-clock.html`을 브라우저 창 두 개로 연다. 하나는 맥 화면, 하나는 탭 화면에 둔다.
2. 두 화면을 휴대폰 카메라로 한 장에 찍는다.
3. 맥 화면 숫자 − 탭 화면 숫자 = 지연(ms). 3번 재서 평균을 낸다.

| 날짜 | 조건 | 1회 | 2회 | 3회 | 체감(커서·스크롤·타이핑·글자) |
|---|---|---|---|---|---|
| 2026-11-25 | M3 Pro MacBook, USB, 기본값(120fps 요청·실제 약 80fps, 40M) | 실측 못 함 | 실측 못 함 | 실측 못 함 | 눈으로 맥 화면과 나란히 비교: 거의 차이 없음 |

## 범위와 알려진 한계

- macOS 전용. Windows, 탭 터치·S Pen 입력, 무선, 오디오는 없다.
- macOS의 FFmpeg 화면 캡처(avfoundation)가 약 80fps에서 막힌다. 120fps가 필요하면 ScreenCaptureKit으로 바꿔야 한다.
- USB를 뽑아도 호스트가 실행 중이면 가상 디스플레이는 남는다. 맥에서는 커서와 창이 그 화면으로 계속 넘어가고, 탭은 마지막 화면에서 멈춰 있다. 다시 꽂으면 자동으로 복구되고 창 배치와 커서 위치도 그대로다.
- 보안: 맥 쪽 소켓은 사용자 전용 `$TMPDIR`의 유닉스 소켓, 탭 쪽은 adb 소켓이며 상대가 adbd(uid 2000)인지 확인한다.
